This repository contains reproducible code for the STA 891 Prelims topic completed by **Arijit Dey** under the supervision of **Professor Amy Herring**.

* The `.txt` files are the raw data files.
* The `.Rdata` files contain the fitted models. These are saved separately so that the models do not need to be refit during knitting, which would be time-consuming.
* The main document is `STA_891_Prelim_WriteUp.qmd`. Knitting this file produces `STA_891_Prelim_WriteUp.pdf`, which is the final written report.
